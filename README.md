# Приложение для анализа банковских операций

## Описание:

Это приложение на Python для анализа транзакций, которые находятся в Excel-файле. 
Приложение будет генерировать JSON-данные для веб-страниц,  
а также предоставлять другие сервисы. 

На данный момент в проекте реализованы следующие функции:
1. Возвращает траты по заданной категории за последние три месяца (от переданной даты)
2. Возвращает JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории
3. Возвращает JSON-ответ со следующими данными:
   Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
   в зависимости от текущего времени.
   По каждой карте:
   последние 4 цифры карты;
   общая сумма расходов;
   кешбэк (1 рубль на каждые 100 рублей).
   Топ-5 транзакций по сумме платежа.
   Курс валют.
   Стоимость акций из S&P500.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/PavelSergeevichA/Transaction_analysis
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Тестирование:

Проект покрыт тестами pytest. Для их запуска выполните команду:
```
pytest
```
